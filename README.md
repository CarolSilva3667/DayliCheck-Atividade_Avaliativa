# Dayli_Check-Atividade_Avaliativa

## Sobre o projeto

O **Daily Check** é uma aplicação web desenvolvida para auxiliar na organização das tarefas do dia a dia de forma prática e intuitiva. O sistema permite adicionar, editar, excluir e acompanhar tarefas, além de oferecer funcionalidades extras como previsão do tempo e controle de temperatura.
O objetivo do projeto é proporcionar uma experiência simples, moderna e funcional para gerenciamento de atividades.

---

# Funcionalidades
1. Adicionar tarefas;
2. Editar tarefas;
3. Excluir tarefas;
4. Listar tarefas;
5. Verificação de temperatura;
6. Consulta de previsão do tempo;
7. Salvamento de informações;
8. Cancelamento de ações;
9. Interface moderna e responsiva;

---

# Tecnologias utilizadas

O projeto foi desenvolvido utilizando:
- HTML5;
- CSS3;
- JavaScript;
- API de previsão do tempo;

# Como executar o projeto
1. Clone o repositório
```bash
git clone https://github.com/seu-usuario/daily-check.git
```
2. Acesse a pasta do projeto
```bash
cd daily-check
```
3. Abra o arquivo `index.html`
Você pode abrir diretamente no navegador ou utilizar a extensão **Live Server** no VS Code.
---

# Como usar

## Adicionar tarefa
1. Clique no botão de adicionar.
2. Digite o nome da tarefa.
3. Salve as informações.

## Editar tarefa
1. Clique no botão de edição.
2. Altere as informações desejadas.
3. Clique em salvar.

## Excluir tarefa
1. Clique no botão de excluir.
2. Confirme a ação.

## Ver previsão do tempo
1. Clique no botão de temperatura.
2. Consulte as informações climáticas.
